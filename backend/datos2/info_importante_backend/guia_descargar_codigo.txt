1. Descarga MariaDB para Windows desde:
🔗 https://mariadb.org/download/

2. Añadir /bin al path

3. Inicio Servicio: net start MariaDB

4. Conectarse a MariaDB: mariadb -u root -p

5. Crear base de datos: mariadb -u root -p birdeep < "./dump_db.sql"

6. Crear usuario:

USE birdeep
CREATE USER 'birdeep_user'@'localhost' IDENTIFIED BY 'clave'; 
GRANT ALL PRIVILEGES ON birdeep.* TO 'birdeep_user'@'localhost';
FLUSH PRIVILEGES;
EXIT;


7. En config.py cambiar: SQLALCHEMY_DATABASE_URI = 'mysql+pymysql://birdeep_user:clave@localhost/birdeep'



Todas instalaciones:
pip install librosa flasgger flask-sqlalchemy python-dateutil pandas flask-jwt-extended flask-cors pymysql pytest

Arrancar servidor:
py app.py

Test: 
pytest test_app.py -v




Base de datos:

mariadb -u birdeep_user -p
USE birdeep;
SHOW TABLES;

SELECT * FROM locations;
DELETE FROM diagnostics;
DELETE FROM diagnostics WHERE id_diagnostic = 3;

SHOW COLUMNS FROM microphones;
